# Brand

The Execution Associates lockup as isb's web app ships it (`isb web/src/assets/brand/exa-lockup@2x.png`, `@3x`): a white mask the app tints with its text colour. Settings' footer shows it, linking to execution.associates. `build-app.sh` copies this folder into the bundle's `Contents/Resources/Brand`.

`monogram-template*.png` (18, 36 and 54 px) is the EXA monogram cut from `../AppIcon.png` as a menu-bar template: the white strokes opaque, everything else transparent.
