# Resources

- `AppIcon.png`: the app icon at 1024 px. It is the Execution Associates monogram exactly as `exa/brand-assets/logo/exa-mark-white.png` draws it, at 54% of a macOS icon plate (824 px, 185 px corners, on the 1024 grid) filled with the rail's ink gradient (`#352545` to `#12071F`), with the standard soft shadow. `build-app.sh` cuts it into an iconset and packs `AppIcon.icns` with `sips` and `iconutil`.
- `Fonts/`, `Sounds/`, `Brand/`, `Icons/`: see the README in each.
